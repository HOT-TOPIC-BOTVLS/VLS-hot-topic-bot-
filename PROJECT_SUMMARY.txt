QUICK START
================================================================================

1. Setup Environment:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

2. Configure:
   cp .env.example .env
   # Edit .env with DISCORD_TOKEN and OWNER_ID

3. Run:
   python main.py

4. Setup in Discord:
   !setupwizard

5. Test:
   !setupcheck
